⚙️ ¿Cómo configurar la Sincronización Automática?

  1. Crea una Google Sheet con las columnas: Ticket, Cliente, Fecha, Pago, Total, Pedido, Estado.
  2. Abre Extensiones > Apps Script, borra el editor y pega este código: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.number,
    data.customer,
    data.date,
    data.paymentMethod,
    data.total,
    data.items,
    data.status
  ]);
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
  3. Haz clic en Implementar > Nueva Implementación, selecciona Aplicación Web, en "Quién tiene acceso" pon Cualquiera e impleméntalo. Copia la URL de Aplicación Web resultante y pégala arriba.

🎥 ¿Cómo usar el sitio de reservas?

Pasos rápidos para reservar:

  1. Selecciona tus alimentos favoritos del Menú del Día.
  2. Personaliza las opciones de preparación para platillos preparados (sin, normal o extra ingredientes).
  3. Ingresa tu nombre en el panel del pedido y haz clic en Confirmar Reserva.
  4. Selecciona tu Método de Pago preferido.
  5. ¡Listo! Guarda tu Código QR generado o captura de pantalla para consultar el estado en tiempo real.
